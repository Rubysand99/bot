# assets/autobuy
- `card_bg.png` — nền ảnh card (lấy từ bot autobuy, 5 file bg1..bg5 gốc giống hệt nhau).
- `font.ttf` — DejaVu Sans Bold (giấy phép tự do Bitstream Vera/DejaVu), dùng để vẽ chữ trên card.
- Muốn chữ kiểu Minecraft: tự bỏ file `Minecraft.ttf` vào thư mục này (không kèm repo vì bản quyền) — bot ưu tiên nó.
